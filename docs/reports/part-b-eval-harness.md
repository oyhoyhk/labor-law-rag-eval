# Part B 리포트: 전체 정답률 헤드라인 + 100문항 Gold Set + 노이즈 바닥·문항 대응 CI 판정, 최소 검출 효과 0.105 → 0.062

> 대상: 평가 체계 현재 상태(GT v2.2, judge-v2, 2026-10-03) · 근거 수치는 모두 저장소 파일에서 인용, 표마다 출처 경로 표기
> 관련: 서비스 [part-a-rag-service.md](part-a-rag-service.md) · 개선 실험 [part-c-experiments.md](part-c-experiments.md)

## 결론

- 헤드라인 지표 **M0 전체 정답률**: 100문항 중 올바르게 처리한 비율 — 답할 문항 92개는 정답 포인트 전부 충족(완전 정답), 거절할 문항 8개는 거절
- 보조 지표 M1~M6: 검색·거절·인용은 결정적 계산, 정답 포인트·근거 없는 주장·시점 오류는 이진 체크리스트 LLM Judge
- 분모 원칙: "얼마나 해냈나"(재현율형)는 거절을 0점으로 포함, "한 것 중 얼마나 맞았나"(정밀도형)는 답변한 문항만 → 어려운 문항 거절로 점수를 올리는 생존자 편향 차단
- Gold Set 100문항: 5단계 이력(v1 56 → v1.1 61 → v2 100 → v2.1 판례형 전환 → v2.2 사후 수정 3건), 전 문항 사람 확인, 실험 대상 유형은 코퍼스 구조에서 블라인드 추출
- Judge 신뢰성: 정답 포인트 사람 판정 일치 95.9% · κ 0.78(채택), 근거 없는 주장 κ 0.54(보조 지표로 강등), 동일 답변 3회 채점 일치 98~99%
- 판정 규칙: 동일 설정 3회 실행으로 노이즈 폭 측정 → |Δ| > 노이즈 폭 **그리고** 문항 대응 부트스트랩 95% CI가 0 제외일 때만 개선·악화, 기준선은 3회 문항별 평균
- 평가 체계 개선 실측: 전체 최소 검출 효과(MDE) 0.105 → 0.062, 예외·분할 유형은 판정 불가 → 판정 가능
- 자기 점검으로 발견·수정한 결함 2건: 질문 범위를 넘는 정답 포인트 3건(v2.2), 단일 기준선의 평균 회귀(다회 기준선 평균으로 전환)
- `make eval` 단일 명령 → `report.md` · `scores.jsonl` · `manifest.json`(모델·seed·프롬프트·Corpus·GT 해시·비용)

## 2. 품질 정의: M0 전체 정답률 0.717 → 0.777, 재현율형은 거절을 0점으로

- 분모는 GT 필드(기대 응답·정답 근거·단계)와 실행의 응답 상태만으로 기계적으로 결정 (`eval/metrics.py`)
- 재현율형 = 거절을 0점 포함: 고정 길이 분할 실험(1차)에서 답변 기준 정답 포인트 0.916이 기준선 0.904보다 높게 보인 생존자 편향을 계기로 도입 (`docs/findings/2026-10-02-exp-config.md`)
- 정밀도형 = 답변한 문항만: 거절은 아무것도 내놓지 않으므로 정밀도 정의 불가 → 답변율·과잉 거절과 함께 해석
- M0을 헤드라인으로 둔 이유: 답변 품질과 거절 정확도를 한 수치로 묶음, 사용자 관점의 "맞게 처리됐나"와 일치

## 4. 편향과 한계: 단일 작성 계열·비블라인드 사람 확인·실험 유형 과대 표집

- 작성 계열: 전 문항 AI(Opus) 초안, v2 재검토도 동일 계열
- 사람 확인: 단일 검토자, 블라인드 아님(작성·재검토 결과를 본 뒤 동의/이의) → 동조 편향 가능
- 질의 문체: 법률 문어체 비중 높음, 실사용 구어 질의 미수집
- 판례 선정: 쟁점이 명확한 판례 위주 → 실제 분쟁의 모호성 과소 대표
- 분포: 실험 대상 유형을 의도적으로 늘린 구성 → 전체 평균은 실사용 성능 추정치가 아님
- 포화: 2차 실행 11개 전부에서 정답인 답할 문항 34개, L1 10문항 중 9개 포함 → L1은 판별력 거의 없음 (§9)
- 범위: 정답 판례 9건이 판례 풀 400건에 포함된 조건의 측정 — 판례 수집 범위 밖 질문의 성능은 미측정
- 사후 수정: v2.2는 결과를 본 뒤의 수정 → 수정 전후 수치를 함께 기록해 선택 편향 노출(§9)

## 10. 지표 맹점 정리: 평가 체계가 틀릴 수 있는 지점 6가지

- **범위 밖 거절**: 2026-10-03 이전에는 "근거 없음"을 밝히고 부가 설명을 붙인 답변·틀린 전제를 바로잡은 답변을 실패로 셈(g039·g041) → 이후 Judge의 결론 단정 여부(asserts_conclusion=false)면 정답으로 정의 변경, 저장된 실행 전체 재채점(LLM 재호출 없음). 남은 한계: 판정이 Judge 의존
- **과잉 거절**: 오답 → 거절 전환도 악화로 셈, M2는 CI 없이 노이즈 폭만으로 판정
- **인용 정밀도**: 보조 근거와 잘못된 근거 미구분 → 판례·관련 조 인용이 늘면 구조적 하락
- **정답 포인트**: 답변 기준 지표는 거절 증가 시 생존자 편향 → 거절을 실패로 세는 완전 정답을 주 지표로
- **근거 없는 주장**: κ 0.54, 주장 분해 정정 맹점
- **흔들림 문항**: 동일 설정에서도 결과가 바뀌는 문항(기준선 21개, 최종 14개) → 개별 문항 변화 해석 제외, 다회 기준선 평균 필수
