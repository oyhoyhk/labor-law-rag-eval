## 결론

- **표적 문항 g013 해결**: 제18조③ 주입으로 정답 포인트 0→1, 인용 정밀도 0.25→1.00, 근거 없는 주장 0.29→0
- **전체 지표 Δ는 모두 노이즈 폭 이내**, 부트스트랩 95% CI도 전부 0 포함 → 판정 "유의하지 않음"
- **검색 단계 효과는 결정적으로 확인**: 확장 포함 Recall@k(all) 43/57 → 45/57(0.75 → 0.79), 신규 도달 gold 조문 2건
- **역참조 블록 정밀도 낮음**: 주입 20블록 중 gold 2건(10%), 인용 3건 — 문장 단위 단서 분류의 오탐이 원인
- 토큰 증가 제한적: 생성 입력 평균 3,701 → 3,902 토큰(+5.4%), 블록 추가 문항 13/61
- 권고: 옵션은 기본 off로 병합 가능, 기본 on 전환은 단서 분류 정밀화 후 재측정

## 가설

- 같은 법 안의 조문 참조("제N조…")를 Provision Graph에 추가하고, 검색된 조문을 **예외·제외·준용 표현으로 참조하는 조문**을 함께 주입
- 기대: 예외 의존 문항(g013)에서 M1(확장 포함)·M4 상승, 추가 토큰은 상한으로 제한
- 근거 관측: g013 "주 12시간 아르바이트생 주휴·연차" — 제55조·제60조는 검색, 결정 조문 제18조③은 64위로 누락 → 오답

## 구현

- 그래프(`app/ingest/provision.py`)
  - "제N조" 열거를 같은 법 참조로 추출, 열거 연속("제7조, 제9조, 제20조부터 제22조까지")은 앞 참조의 법령을 상속
  - 제외 접두: 「타법」, 「…」(이하 "…법"), 법·영(위임), 시행령, 같은 법 — 단 "이 법/영/규칙"은 같은 법
  - 단서 분류(참조가 속한 문장 기준): exception(적용하지 아니한다·에도 불구하고·제외·예외로 한다) > mutatis(준용) > plain
  - 노드 필드 추가: `references`, `reference_cues`, `referenced_by`, `referenced_by_cues` (기존 필드 변경 없음)
  - 규모: 같은 법 참조 간선 701개(exception 57 · 준용 48 · plain 596), 참조 보유 조문 282개
- 파이프라인(`app/rag.py`, `Options.expand_reverse_refs=False`)
  - 대상: 상위 3개 검색 조문의 `referenced_by` 중 exception·준용 단서만, plain 제외
  - 순서: 참조하는 상위 조문 수(내림차순) → 단서(exception 우선) → 참조 대상 순위
  - 상한: 최대 2블록(`MAX_REVERSE`), 위임 확장 상한(3)과 별도
  - 표시: `linked=true` 유지(응답 스키마 불변), 머리말 "제N조의 예외·준용을 정한 조문"
