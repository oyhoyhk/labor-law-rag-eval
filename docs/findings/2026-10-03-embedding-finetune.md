# 임베딩 모델 교체와 파인튜닝 실험

> 결과: `eval/results/embeddings/` (grid.tsv · big.tsv · qwen_ft*.tsv · v3.tsv · 로그 · train_meta) · 전체 정답률: `eval/results/v2/v2-qwen3-{4B,8B}` · GPU 작업 기록: `docs/ops/2026-10-03-gpu-log.md`
> 비용: GPU A100 80GB 약 2시간 55분(약 7,300원) + Luna(학습 데이터 생성 822원, 전체 정답률 측정 1,029원)

## 결론

- **임베딩 모델 교체가 유일하게 유효한 개선**: KURE-v1 → Qwen3-Embedding-4B, 3회 평균 전체 정답률 0.777 → **0.840(+6.3%p, CI 하한 −1%p 경계)**, 검색 정답 조문 전부 0.696 → 0.772·정답 포인트 +0.058·시점형 +0.147(모두 유의)
- **파인튜닝은 효과 없음**: KURE 전체 학습 9개 설정, Qwen3 4B·8B LoRA 6회 모두 원본 대비 개선이 학습 시드 흔들림 수준 이하
- **학습 데이터 질 개선(v3)의 KURE 상승은 누수성**: v3로 KURE 검색 전부 0.696 → 0.761이었으나, GT 근거 조문을 학습에서 뺀 엄격판에서는 0.696(원본과 동일) → 질문 유형 보강 효과가 아니라 GT가 묻는 조문을 미리 학습한 효과

## 3. KURE 파인튜닝 (전체 학습, v2 3,200쌍, A100 1회 약 90초)

| 설정 | dev 전부 / MRR |

| 기본(시드 42 / 7) | 0.675 / 0.815 · 0.700 / 0.848 |

- 로컬(M5 Pro) 학습은 스텝당 약 3분(1회 약 10시간) → GPU 필요

## 4. Qwen3 LoRA (r=16, 어텐션 투영, 학습 파라미터 0.29%)

| 모델 | 전체 92문항: 1개 이상 / 전부 / MRR |
|---|---|
| 원본 4B | 0.946 / **0.772** / 0.869 |
| 4B LoRA 시드 42 · 7 | 0.967 / 0.739 / 0.871 · 0.967 / 0.739 / 0.874 |
| 원본 8B | 0.957 / **0.772** / 0.848 |
| 8B LoRA 시드 42 · 7 | 0.978 / 0.761 / 0.846 · 0.978 / 0.761 / 0.853 |

- 공통 패턴: 정답 조문 1개 이상은 +2문항, 전부 찾기는 −1~3문항 → 정답 1개 위주 학습 데이터가 "최상위 1개"에만 맞춤
- 첫 시도 OOM(배치 16×512토큰 활성값 > 80GB) → Cached MNRL(4개씩) + gradient checkpointing으로 약 9~17GB

## 5. 학습 데이터 v3: 여러 조문·사례형 질문 추가

| 데이터 | 구성 | KURE 전체 92문항 전부 / MRR | Qwen3-4B LoRA 전부 / MRR |
|---|---|---|---|
| (원본 모델) | — | 0.696 / 0.801 | 0.772 / 0.869 |
| v2 | 3,200쌍, 정답 1개 위주 | 0.717 / 0.841 | 0.739 / 0.871 |
| v3 | + 여러 조문 655(정답 2개) + 사례형 850 = 4,705 | **0.761** / 0.834 | 0.739 / 0.870 |
| v3 엄격판 | v3에서 GT 근거 조문이 정답인 쌍 제외, 3,580 | 0.696 / 0.805 | 0.739 / 0.854 |

- 표본 품질(Opus): 여러 조문 12/15(두 조문 모두 필요), 사례형 14/15
- KURE v3 상승(+6문항, test에서도 0.712 → 0.769)은 엄격판에서 소멸 → GT 근거 조문 중복 학습 효과, 일반화 개선 근거 아님
- Qwen3-4B는 v3로도 변화 없음 → 원본이 이미 이 데이터가 가르치는 범위를 넘어섬
- 한계: 실패 유형 진단(여러 조문·사례형)을 dev가 아닌 GT 전체 결과에서 도출 → 엄격판·test로 보완

## 6. 반복 측정으로 확정 (각 모델 3회, 양쪽 모두 문항별 3회 평균으로 비교)

| 지표 | KURE (3회) | Qwen3-4B (3회) | Qwen3-8B (3회) |
|---|---|---|---|
| 전체 정답률 | 0.79 · 0.76 · 0.78 | 0.86 · 0.83 · 0.83 | 0.81 · 0.83 · 0.84 |
| 평균 | 0.777 | **0.840** | 0.827 |

| 비교 (3회 평균 대 3회 평균) | 전체 정답률 Δ (95% CI) | 정답 포인트 Δ | 검색 전부 Δ | 인용 정밀도 Δ |
|---|---|---|---|---|
| KURE → 4B | +0.063 (−0.010, +0.140) | **+0.058 유의** | **+0.076 유의** | −0.004 |
| KURE → 8B | +0.050 (−0.020, +0.120) | **+0.060 유의** | **+0.076 유의** | **−0.047 유의 악화** |
| 4B → 8B | −0.013 (−0.063, +0.037) | +0.002 | 0 | **−0.044 유의 악화** |

- **정정**: 1회 측정에서 "전체 정답률 +8.3%p 유의"였던 4B는 첫 실행이 3회 중 가장 높았던 결과(0.860) → 3회 평균끼리 비교하면 +6.3%p, CI 하한 −1%p로 경계(유의 판정 미달)
- 그래도 4B 3회(0.83~0.86)가 KURE 3회(0.76~0.79)와 범위가 겹치지 않고, 검색·정답 포인트·시점형(0.680 → 0.827, 유의)은 유의 개선
- 8B: 4B 대비 전체 정답률 차이 없음(노이즈 내), 인용 정밀도만 유의 열세 → 4B 우위 확정
- 범위 밖 거절(3회): KURE 1.00·0.75·0.875, 4B 0.875·0.875·1.00, 8B 0.875×3 — 실패는 모두 g039·g041 유형(지표 맹점)
- 결론: Qwen3-Embedding-4B 채택 권고, 근거 표현은 "검색·정답 포인트·시점형 유의 개선, 전체 정답률 +6.3%p(경계)"
