# 임베딩 모델 교체와 파인튜닝 실험

> 결과: `eval/results/embeddings/` (grid.tsv · big.tsv · qwen_ft*.tsv · v3.tsv · 로그 · train_meta) · 전체 정답률: `eval/results/v2/v2-qwen3-{4B,8B}` · GPU 작업 기록: `docs/ops/2026-10-03-gpu-log.md`
> 비용: GPU A100 80GB 약 2시간 55분(약 7,300원) + Luna(학습 데이터 생성 822원, 전체 정답률 측정 1,029원)

## 결론

- **임베딩 모델 교체가 유일하게 유효한 개선**: KURE-v1 → Qwen3-Embedding-4B, 3회 평균 전체 정답률 0.777 → **0.840(+6.3%p, CI 하한 −1%p 경계)**, 검색 정답 조문 전부 0.696 → 0.772·정답 포인트 +0.058·시점형 +0.147(모두 유의)
- **파인튜닝은 효과 없음**: KURE 전체 학습 9개 설정, Qwen3 4B·8B LoRA 6회 모두 원본 대비 개선이 학습 시드 흔들림 수준 이하
- **학습 데이터 질 개선(v3)의 KURE 상승은 누수성**: v3로 KURE 검색 전부 0.696 → 0.761이었으나, GT 근거 조문을 학습에서 뺀 엄격판에서는 0.696(원본과 동일) → 질문 유형 보강 효과가 아니라 GT가 묻는 조문을 미리 학습한 효과

- 결론: Qwen3-Embedding-4B 채택 권고, 근거 표현은 "검색·정답 포인트·시점형 유의 개선, 전체 정답률 +6.3%p(경계)"
