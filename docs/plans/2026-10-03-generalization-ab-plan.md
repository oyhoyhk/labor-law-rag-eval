## 측정

- 각 방법 3회 실행(`--no-cache`), 전체 100문항, 기준선 3회와 문항 단위 3회 평균끼리 비교
- 판정 지표: 전체 정답률(M0) — paired bootstrap 95% CI 하한 > 0 이고 Δ > 노이즈 바닥(±0.030)이면 **유의 개선**
- 보조 지표: 완전 정답, 검색 정답 전부, 정답 포인트, 인용 정밀도, 근거 없는 주장, 과잉 거절, 범위 밖 거절, 비용·지연
- 부작용 감시: 범위 밖 거절 하락, 기준선 정답 문항의 오답 전환 수
- 과적합 감시: 방법 설계를 전체 GT 실패 문항에서 도출 → dev/test 각각의 Δ 보고, test에서 방향 불일치 시 채택 보류

## 채점자 의존성 통제

- Luna가 기준선보다 후하게 줄 위험(체크리스트·검증은 답변을 길게 만듦) → **유의 개선으로 판정된 방법은 Opus·Codex로 3회 답변 전체 재채점**(`eval/rejudge.py --all`)
- 채택 조건: Luna 기준 유의 개선 + Opus 기준 Δ 방향 동일(CI 하한 > 0 권장, 미달 시 "Luna 한정 개선"으로 보고)

## 결합 검증

- 채택된 방법 전부를 켠 결합 구성 3회 → 기준선 대비 같은 판정 규칙 + Opus·Codex 재채점
- 결합 효과가 개별 최대 효과보다 작으면 상호 간섭으로 보고, 가장 좋은 단일·쌍 조합 추가 측정 여부는 결과 보고 후 결정
