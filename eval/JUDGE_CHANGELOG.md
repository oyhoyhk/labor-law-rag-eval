# Judge 프롬프트 변경 이력

## judge-v2 (2026-10-02)
- 대상: grounding(M5 근거 없는 주장)
- 변경
  - 질문에 주어진 사실의 재진술, 메타 진술(근거 유무·추가 정보 필요) 제외
  - 근거 문장 + 질문 사실로 반드시 도출되는 결론·계산은 supported로 인정, `derived` 표시
  - Judge 입력에 질문 추가
- 근거: baseline(judge-v1) 점검에서 오판 3유형 확인
  - g027: 질문 전제("만 6년")와 조문 계산 결과("17일")를 unsupported 처리
  - g032: 조문에서 바로 나오는 결론("현재는 안 됩니다")을 unsupported 처리
  - l5a03: "근거 블록에 내용이 없다"는 메타 진술을 주장으로 집계
- 주의: 점검은 baseline 전체 출력 기준이며, 오판 유형이 문항 특이가 아닌 일반 규칙 수준이라 test 과적합 위험 낮다고 판단
