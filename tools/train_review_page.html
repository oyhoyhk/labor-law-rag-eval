학습 데이터 표본 검수

임베딩 파인튜닝용 (질문, 정답 조문) 3,519쌍 중 출처별 무작위 40쌍. Claude Opus와 Codex(gpt-6-astra)가 같은 기준으로 각각 판정하고 이유를 남김(두 모델 일치 35/40). 맞는 쪽에 동의하거나 직접 선택. 결과는 학습 데이터 정확도 추정에 사용

적합: 질문의 답(또는 핵심 근거)이 이 조문에 있음 부적합: 이 조문으로는 답할 수 없음, 질문이 어색해 쓸 수 없음 애매: 관련은 있지만 다른 조문이 더 맞음, 판례 쟁점과 조문의 관련이 간접적임 판례 출처는 정답 조문이 여러 개(판례의 참조조문 전체)이며, 그중 하나라도 맞으면 적합
