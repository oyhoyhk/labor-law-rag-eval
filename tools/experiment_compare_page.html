Part C 실험 비교

노동법령 RAG의 구성을 하나씩 바꿔 가며, 100개 질문 중 몇 개를 올바르게 처리하는지 비교한 결과입니다. 비교 기준(기준선)은 판례 없이 조문만 쓰는 처음 구성입니다.

한눈에 보기: 전체 정답률

괄호 안: 기준선 대비 변화 · 판정 · 근거. 95% 범위 = 문항을 무작위로 다시 뽑아 계산한 변화의 범위로, 0을 포함하면 "효과 없음"일 가능성을 배제할 수 없어 판단 보류. 맞힘/틀림 = 기준선 대비 새로 맞히거나 새로 틀린 문항 수. 100문항 중 올바르게 처리한 비율. 답할 수 있는 질문은 필요한 내용을 빠짐없이 답해야, 답할 수 없는 질문은 거절해야 정답. 회색 띠는 같은 구성을 여러 번 돌려도 생기는 흔들림 범위라서, 막대 끝이 띠 안에 있으면 우연과 구별할 수 없음

무엇을 바꿨나: 컨텍스트 구성 단계

모든 실험은 "질문이 들어왔을 때 LLM에게 어떤 근거를 어떻게 넣어 주느냐"를 바꾼 것. 버튼을 누르면 기준선과 달라진 단계가 강조되고 결과가 함께 표시됨. 채점 방식(하네스)은 모든 구성에서 동일

모든 구성을 표로 보기 (바뀐 칸만 색 표시)

실험별 한 줄 결론

개선 시도는 좋아지길 기대한 변경, 확인 실험은 일부러 기능을 빼서 그 기능이 정말 필요한지 확인한 변경(나빠지는 것이 예상대로)

노린 문제를 고쳤나

각 실험이 겨냥한 유형의 질문만 따로 센 결과. 문항 수가 9~25개라 2~3문항 차이는 우연일 수 있음

기준선
비교 기준이 되는 처음 구성. 같은 구성을 3번 돌린 평균을 사용
좋아짐 · 나빠짐
변화가 흔들림 범위보다 크고, 문항을 무작위로 다시 뽑아 계산해도 같은 방향이 유지될 때만 붙임(통계적으로 유의)
판단 보류
숫자는 바뀌었지만 우연히 생길 수 있는 크기라서 효과가 있다고 말할 수 없음
완전 정답
답할 수 있는 질문에서 필요한 사실(정답 포인트)을 하나도 빠뜨리지 않은 답변
자세한 지표 보기 (지표별 표 · 실험 상세 · 비용)

지표별 판정 매트릭스

셀 = 실험값과 기준선 대비 Δ. 색은 유의 판정만 표시하고, 노이즈 안의 변화는 회색으로 둠. 열 머리를 누르면 아래 상세가 그 실험으로 바뀜. 셀에 마우스를 올리면 노이즈 범위와 CI 확인 가능

▲ 개선▼ 악화· 유의하지 않음 ↓ = 낮을수록 좋음

유형별 완전 정답

실험이 노린 문항 유형만 떼어 본 완전 정답(정답 포인트 전부 충족, 거절은 실패). 유형은 코퍼스 구조에서 계산(eval/tags.py). 문항 수가 작아 2문항 변화(+0.167)도 신뢰구간 하한이 0이면 유의 판정에서 제외됨

실험 상세

개선 방향으로 정렬한 Δ(오른쪽 = 좋아짐). 회색 띠는 노이즈 범위, 가는 선은 95% CI

비용과 입력 토큰
